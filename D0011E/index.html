Built a complete 32-bit MIPS processor from scratch, starting from a single logic gate, assembling a full adder, scaling to a 32-bit ALU, and finishing with a CPU that executes real assembly programs including an integer division routine. Written in Veryl, a modern hardware description language that compiles to SystemVerilog.

Course labs

L2
Combinational Logic & BCD Checker
Designed logic circuits in Veryl for a 4-bit BCD digit checker that computes max, min, even, lo3, noBCD, and hieq3 from boolean expressions. Visualised netlists in DigitalJS via Yosys, performed Karnaugh minimisation, and implemented PLD cell arrays. Verified every output using Verilator testbenches with exhaustive assertions.
L3a
4-bit ALU: Full Adder → Arithmetic + Logic Unit
Built a 1-bit full adder, chained four into a ripple-carry adder, then wrapped it in an arithmetic unit supporting ADD and SUB with signed overflow (V) and carry (C) flags. Added a 4-bit logic unit for AND and OR. Verified signed and unsigned arithmetic edge cases with complete truth tables and simulation waveforms.
L3b
32-bit ALU + Program Counter
Scaled the 4-bit ALU to 32 bits using a generate loop over 32 full adders. Extended it with AND, OR, and SLT via a 4-to-1 mux, plus a zero flag (Z). Designed a clocked program counter that increments by 4 each cycle with async reset, the first sequential component in the processor.
L4
Simplified Single-Cycle MIPS Processor
Wired everything together: instruction memory, register file, sign-extend unit, control decoder, ALU, and muxes in a top-level module. Implemented the full MIPS single-cycle datapath for 7 instructions: ADD, SUB, AND, OR, SLT, ADDI, SLTI. Wrote a testbench that steps through the program and asserts correct register values every clock cycle.
L5
Full MIPS: Data Memory, Branch, Jump & Integer Division
Added data memory (LW/SW), branch (BEQ with signed offset × 4), and jump (J with 26-bit absolute target). Wrote MIPS assembly for integer division using repeated subtraction and hand-translated it to machine code. The final processor executes the full program and stores quotient + remainder in data memory, verified by assertions in the testbench.
