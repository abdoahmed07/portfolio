🔌
Why Socket.io over SSE
Presence (who's viewing) needs bidirectional communication. Server-Sent Events are one-directional, so they can't tell the server when a user joins or leaves. Socket.io also handles reconnection automatically, which matters for a real-time app.
🔑
JWT in memory, not localStorage
Storing tokens in localStorage makes XSS attacks more dangerous, any malicious script can read it. Keeping the token in React state means it dies on refresh, an acceptable trade-off for this app. In production, httpOnly cookies would be the better choice.
🎲
crypto.randomBytes over nanoid
nanoid v4+ is ESM-only, which breaks CommonJS require. Node's built-in crypto.randomBytes(6).toString('base64url') gives the same 8-character URL-safe ID with no extra dependency.
🏗️
Railway + Vercel, not one platform
Vercel's CDN is faster for static assets. Railway handles long-lived WebSocket connections better than serverless functions, which have timeouts that would kill a Socket.io connection mid-session.
