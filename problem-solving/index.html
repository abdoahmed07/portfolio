Most interview problems reduce to a handful of recognizable patterns. These four came up constantly.

🗺️
Hash map lookup
Two Sum, Group Anagrams, Top K Frequent. Whenever a problem needs "have I seen this before" or "how many of these exist," a hash map turns an O(n²) scan into O(n).
🌳
Tree recursion
Solve for the root, trust the recursive calls to solve the subtrees. The one recurring mistake: validating a BST by checking only immediate children instead of passing down a valid range.
🕸️
Graph traversal
Number of Islands, Clone Graph, Course Schedule. Connected components, cycles, and shortest paths are all BFS/DFS with a visited set, the hard part is picking which one and what "visited" means.
🎯
Three-Color DFS
Cycle detection needs more than a simple visited/unvisited flag. Marking nodes unvisited, in-progress, and done distinguishes "revisiting a node in the current path" (a real cycle) from "revisiting a node we already fully explored" (not a cycle).
