About Us

Islam Kindles is a student portfolio project built to practice web development while creating something meaningful.

01. Our Story

Where it started

Islam Kindles was created as a practice website project to gather different Islamic topics in one place. The goal is to make the content simple, clear, and easy to explore.

02. Our Mission

What we're doing

Organize useful sections such as Quran, Hadith, and answers to common questions in a clean and simple website that anyone can use.

03. The Project

Built for learning

This website is part of a student portfolio, built to practice HTML, CSS, JavaScript, and website structure, while also creating something with real purpose.
